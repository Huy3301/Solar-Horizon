# Solar Horizon

> **"No Man's Sky meets real astronomy."**

**Solar Horizon** is an open-source, seamless space exploration game built with [Godot Engine 4.7.2-stable](https://godotengine.org/). Players start at **Adelaide Base** on Earth within an astronomically authentic Sol system, uncover the mysterious *Horizon Signal*, and journey into an expansive, physically derived procedural galaxy. From full Keplerian orbital mechanics and hypersonic atmospheric re-entry to surface rover traversal, on-foot surveying, and outpost construction, Solar Horizon blends plausible aerospace simulation with rich planetary survival. The project targets desktop platforms (Forward+ renderer) and mobile flagships led by the **Samsung Galaxy S26+** (Mobile renderer, Vulkan).

> **Status:** `Pre-alpha / Phase 0–1 Overhaul` &nbsp;|&nbsp; **Engine:** `Godot 4.7.2-stable` &nbsp;|&nbsp; **Physics:** `Jolt 3D` (Physics Interpolation Enabled)

### Current Implementation vs. Planned Features

| Feature Domain | Current Prototype State | Planned Overhaul Target |
|---|---|---|
| **World Scale** | 50 km "toy" Earth mesh with hardcoded `g = 9.81 m/s²` | Real-scale Sol system (≈1:10 planetary radius design compression, e.g. Earth radius ≈ 637 km; 1:100+ interplanetary spacing with pulse drive) |
| **Precision & Coordinates** | 32-bit `Vector3` with non-functional floating origin | Double-precision universe coordinates (`DVec3` / `UniversePosition`) with an automated `OriginService` rebasing local space every 2–5 km |
| **Planetary Terrain** | Static 256×128 `SphereMesh` with 2K texture; initial compute spike | Seamless Quadtree cube-sphere with CDLOD, vertex geomorphing, boundary skirts, and GPU compute heightmaps/normals |
| **Atmosphere & Sky** | Fresnel rim shader hack + static sky dome | Precomputed Hillaire 2020 scattering LUTs (Rayleigh/Mie), aerial perspective froxels, and star-catalogue skybox |
| **Flight Dynamics** | RigidBody flight controller with hardcoded Earth gravity | Dual-tier `FlightModel`: **Assisted** (accessible fly-by-wire, auto-level, pulse drive) + **Newtonian Pro** (full Keplerian orbital dynamics, Hohmann transfers) |
| **Orbital Mechanics** | State-vector conversion script; faked HUD heuristics | Patched-conic Kepler propagation, Sphere of Influence (SOI) transitions, real Ap/Pe/eccentricity HUD telemetry |
| **Player Controller** | Ship flight only (keyboard/mouse) | Multi-mode `PlayerRig`: ship flight, rover surface traversal, and first/third-person on-foot exploration (walk, sprint, jetpack, mining laser, visor scanner) |
| **Gameplay Loops** | Flight sandbox without progression | Core survival loop: Life support → Scan & Catalogue → Harvest & Refine → Craft & Upgrade → Outpost Construction → Interstellar Travel |
| **Controls** | Legacy keyboard-only bindings | Complete unified input map: Keyboard & Mouse, Gamepad, and responsive Virtual Touch controls |
| **Testing & CI** | Manual testing | Headless Godot unit test suite (`tests/run_tests.gd`) and automated import validation (`tools/validate.ps1`) |

## Requirements

* **Game Engine:** [Godot Engine 4.7.2-stable](https://godotengine.org/download/) (Standard 64-bit edition; .NET is not required).
* **Physics Engine:** Godot Jolt Physics (built-in default in Godot 4.4+).
* **Physics Interpolation:** Enabled (ensures stutter-free rendering on high-refresh 120 Hz displays).
* **Target Hardware:**
  * **Desktop:** Vulkan Forward+ renderer; DirectX 12 / Vulkan-compatible GPU (NVIDIA GTX 1060 / AMD RX 580 minimum; RTX 3060 / RX 6600 recommended).
  * **Mobile:** Samsung Galaxy S26+ (Exynos 2600 with AMD Xclipse 960 GPU / Snapdragon 8 Elite Gen 5 with Adreno 840 GPU) running Vulkan Mobile renderer.
* **Native Toolchain (Planned):** A C++20 toolchain (CMake/SCons and Clang/GCC/MSVC) will be introduced in Phase 1 for compiling the `solar_core` GDExtension module.

## How to Run

### In the Godot Editor
1. Install **Godot 4.7.2-stable**.
2. Launch Godot, click **Import**, select `project.godot` inside the repository root (`c:/code/Solar-Horizon`), and click **Import & Edit**.
3. Press **F5** to run the active default scene (or open and run prototype scenes such as `game/planet/spike/planet_spike.tscn`).

### Headless Validation & Tests
The project includes automated validation tooling to verify that scripts compile, resources load cleanly, and tests pass without launching a graphical window:

* **Full validation script (PowerShell):**
  ```powershell
  powershell -File tools/validate.ps1
  ```
* **Run unit test suite directly via Godot console binary:**
  ```powershell
  godot --headless --path . --script res://tests/run_tests.gd
  ```

## Controls

The game features a unified, cross-platform input scheme across keyboard/mouse, gamepads, and touchscreen devices.

| Action | Keyboard / Mouse | Gamepad (Xbox / PlayStation) | Touch (Mobile) |
|---|---|---|---|
| **Pitch** | `W` / `S` | Left Stick (Y-axis) | Virtual Stick (Y-axis) |
| **Roll** | `A` / `D` | Left Stick (X-axis) | Virtual Stick (X-axis) |
| **Yaw** | `Q` / `E` | `LB` / `RB` (L1 / R1) | On-screen Rudder buttons |
| **Throttle Up / Down** | `Shift` / `Ctrl` | `RT` / `LT` (R2 / L2) | Vertical Throttle Slider |
| **Landing Gear** | `G` | `Y` / `Triangle` | `[GEAR]` Button |
| **Brakes** | `B` | `X` / `Square` | `[BRAKE]` Button |
| **RCS / VTOL Burst** | `Space` | `A` / `Cross` | `[RCS/VTOL]` Button |
| **Cycle Camera** | `V` | `Back` / `Share` | `[CAM]` Button |
| **Map View** | `M` | `Start` (long-press) / None | `[MAP]` Button |
| **Time Warp Increase** | `.` (Period) | `D-Pad Right` | On-screen Warp `+` |
| **Time Warp Decrease** | `,` (Comma) | `D-Pad Left` | On-screen Warp `-` |

## Platform Targets & Performance Budgets

### Samsung Galaxy S26+ (Mobile Baseline)
* **Target SoC:** Exynos 2600 (AMD Xclipse 960 RDNA GPU) & Snapdragon 8 Elite Gen 5 (Adreno 840 GPU).
* **Renderer:** Godot Mobile renderer (Vulkan Mobile).
* **Frame Rate:** Sustained **60 FPS** in *Performance Mode*; 30 FPS in *Fidelity Mode*.
* **Resolution:** Dynamic render scaling (1560×720 upscaled to FHD+ 2340×1080 via AMD FSR 1.0).
* **GPU Budget:** Average GPU frame time ≤ 12.5 ms (thermal headroom for sustained play without throttling).
* **Memory & Draw Calls:** ≤ 600 draw calls per frame; ≤ 1.5M visible triangles; ≤ 1.2 GB texture VRAM with ASTC compression; ≤ 3.5 GB total resident RAM.
* **Thermal Governor:** Real-time integration with Android Dynamic Performance Framework (ADPF) to scale LOD and shadow cascades ahead of OS thermal throttles.

### Desktop PC (Forward+)
* **Renderer:** Godot Forward+ renderer.
* **Visual Stack:** Full-resolution volumetric clouds and fog, SSAO, SSIL, screen-space reflections (SSR), contact shadows, and FSR 2.0 / TAA anti-aliasing.
* **Target:** 1080p60 on entry hardware up to 4K Ultra at 120+ FPS on modern GPUs.
